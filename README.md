# DragonByte AI

**Your AI-powered cybersecurity learning companion.**

DragonByte AI is a desktop application designed to support cybersecurity students, learners, and enthusiasts with an AI-powered assistant and a dedicated user interface.

## Features

- **AI Assistant:** Ask questions and receive AI-generated responses.
- **Voice Interaction:** Use voice input to interact with the assistant.
- **Text Chat:** Communicate with the AI through text.
- **Voice Output:** Optionally listen to AI responses.
- **Cybersecurity Learning:** Get help understanding cybersecurity concepts and programming topics.
- **Desktop Experience:** A dedicated Windows application.
